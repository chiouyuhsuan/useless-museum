Tech stack
  • Frontend — Vanilla JS (no framework)
  • Cat recognition — TensorFlow.js · MobileNet, in-browser
  • Auth & data — Firebase (Auth + Firestore)
  • Automated prize-check — Google Apps Script + Google Sheets
  • Hosting — GitHub Pages

Built to cost nothing to run — free tiers all the way down. Which is also, quietly, why some of it broke.

Dev diary · a sarcastic post-mortem

Cats bring money — everyone in Taiwan grows up knowing it. But which cat, exactly? LuckyCat started as a simple, slightly unhinged question: if you put every cat on the same lottery and let the numbers pile up, could you eventually prove which face, which coat, is actually the luckiest? A book of cat fortune-telling, rebuilt from crowd data instead of folklore.

It never left friends-and-family testing. The recognition ran on free tiers that broke as often as they worked; the numbers were ninety percent random and ten percent hope. One person's cat did win — but the auto prize-check wasn't finished, so I delivered the good news by hand, over a messaging app. That's why the shelf says 0 Winners.

The full story — the patient-zero cats, the one real win, and how the whole thing got quietly buried under features I was sure I needed — is in the field note below.
